# js-ts-lab

Repositório de estudos avançados em JavaScript e TypeScript, criado para documentar minha evolução prática no desenvolvimento web moderno.

Depois de concluir o curso de JavaScript básico do Estudonauta, com o professor Gustavo Guanabara, iniciei uma nova etapa de aprofundamento em JavaScript e TypeScript, com foco em front-end, back-end, boas práticas de programação e construção de projetos mais completos.

Este repositório funciona como um laboratório de aprendizagem, reunindo exercícios, anotações, testes, experimentos e pequenos projetos desenvolvidos ao longo dos estudos.

## Objetivo

O objetivo deste repositório é consolidar conhecimentos em JavaScript moderno e TypeScript, aplicando os conceitos em exemplos práticos e projetos progressivos.

Além de acompanhar minha evolução técnica, este espaço também faz parte do meu portfólio como estudante de desenvolvimento web em transição de carreira, unindo minha experiência anterior com escrita, ensino, SEO e criação de conteúdo digital ao aprendizado de programação.
